Forex & Commodity Control Panel
A responsive, real‑time market dashboard for monitoring major Forex pairs, commodities, and cryptocurrencies with live prices and technical indicators.

Overview
This web application provides a clean, modern interface to track the most traded financial instruments in real time. It fetches live data from the API (MetaTrader 5 feed) and displays interactive charts and popular technical indicators. The panel is designed for traders, analysts, and anyone interested in market movements.

Key Features
Real‑time quotes for:
Forex: EUR/USD, USD/JPY, GBP/USD, USD/CHF, AUD/USD, USD/CAD, NZD/USD
Commodities: Gold (XAU/USD), Silver (XAG/USD), Crude Oil (USOIL)
Crypto: BTC/USD, ETH/USD, XRP/USD, BNB/USD, SOL/USD, ADA/USD, DOGE/USD, LTC/USD
Interactive candlestick chart (1‑hour timeframe) built with Chart.js.
Technical indicators updated in real time:
SMA (Simple Moving Average) – 20 & 50 periods
EMA (Exponential Moving Average) – 12 & 26 periods
RSI (Relative Strength Index) – 14 periods
MACD (Moving Average Convergence Divergence)
Stochastic Oscillator (%K and %D)
Radar table showing the most overbought (RSI > 70) and oversold (RSI < 30) assets, with green/red dots for quick visual identification.
Auto‑refresh every 5 seconds, plus a manual F5 Refresh button and keyboard shortcut.
Responsive design with soft, muted colors, glassmorphism cards, and smooth animations. Works on desktop, tablet, and mobile.
Financial disclaimer in the footer with a detailed risk warning.
